# AgentPort 中的 easy-pi 会话存储

更新后的 AgentPort 为新建 Pi 会话使用：

```text
~/.epi/agent/sessions/--agentport-<旧专属目录的 SHA256>--/
```

若设置绝对路径 `EASY_PI_CODING_AGENT_DIR`，则使用该目录下的 `sessions/`。每个 AgentPort 会话有独立命名空间；AgentPort ID、Pi native ID 和工作目录保持不变。此调整改变存储位置，不负责安装或选择 easy-pi executable；请在设置中核对 Pi 安装路径。

## 继续旧会话

在更新后的 AgentPort 中，对**已停止**的旧 Pi 会话选择重启并恢复。首次重启会复制原专属 `pi/` 目录（含附属文件）到新位置，校验后发布。原目录保留，不删除、不覆盖。运行中的 host 不会即时切换，也不会因更新 GUI 而停止。

历史、搜索、导出和备份跟随已发布的新副本；尚未切换的会话仍读取旧位置。删除 AgentPort 会话不会自动清理外部 `.epi` 历史。

## 失败与恢复

未知格式、符号链接、重复/不匹配的原生 ID、源数据变化、无归属的目标或损坏的发布标记会阻止迁移/恢复。失败留下的部分目录保留供检查，不会自动重试覆盖；不要手工伪造 `.agentport-origin.json`。发布后若旧副本被继续写入，后续重启将报告分叉冲突，而不是覆盖新历史。处理冲突前保留两份数据并确认旧写入者已停止。

备份读取当前副本，但恢复先写入隔离的 AgentPort 数据目录，不覆盖现有 `.epi`；恢复后的首次显式重启再迁移到自己的命名空间。
